# 🍽️ Site Restaurante — Delícia Passos

## 📌 Sobre o projeto

O **Delícia Passos** é um projeto de site para restaurante desenvolvido durante minha jornada de estudos em **Desenvolvimento Full Stack**.

O projeto foi criado com foco na prática dos fundamentos de **HTML5**, utilizando uma estrutura semântica, acessível e organizada para apresentar informações de um restaurante fictício.

---

## 🎯 Objetivo

Praticar e consolidar os conhecimentos adquiridos em HTML5 por meio da criação de um projeto completo, simulando um site real de restaurante.

O projeto reúne diferentes elementos estudados durante a Fase 2 do curso:

* Estrutura HTML5
* Textos e títulos
* Links
* Navegação interna
* Tabelas
* Formulários
* HTML semântico
* Acessibilidade

---

## 🛠️ Tecnologias utilizadas

* HTML5
* Git
* GitHub

---

## 📚 Conceitos praticados

### Estrutura HTML5

Utilização de:

* `<!DOCTYPE html>`
* `<html>`
* `<head>`
* `<meta>`
* `<title>`
* `<body>`

### HTML semântico

Utilização de elementos como:

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<article>`
* `<address>`
* `<footer>`

### Tabelas

Utilização de:

* `<table>`
* `<caption>`
* `<thead>`
* `<tbody>`
* `<tr>`
* `<th>`
* `<td>`

As tabelas foram utilizadas para organizar o cardápio e os horários de funcionamento.

### Formulários

O projeto possui um formulário para reservas utilizando:

* Nome
* E-mail
* Telefone
* Data
* Horário
* Quantidade de pessoas
* Observação

Também foram utilizados atributos como:

* `required`
* `min`
* `name`
* `id`
* `for`
* `action`
* `method`

### Acessibilidade

Foram aplicadas práticas básicas de acessibilidade, principalmente na associação entre:

```text
<label>
<input>
```

por meio dos atributos `for` e `id`.

## 🚀 Como executar

Como o projeto foi desenvolvido utilizando HTML5, não é necessário instalar nenhuma dependência.

### 1. Clone o repositório

```bash
git clone https://github.com/diego-nascimento-passos/site-restaurante.git
```

### 2. Entre na pasta

```bash
cd site-restaurante
```

### 3. Abra o arquivo

Abra o arquivo:

```text
index.html
```

diretamente no navegador ou utilize o **Live Server** no VS Code.
